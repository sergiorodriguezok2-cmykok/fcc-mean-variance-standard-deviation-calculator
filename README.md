# Calculadora estadística

Solución del proyecto de freeCodeCamp.

Calcula media, varianza, desviación estándar, máximo, mínimo y suma por columnas, filas y matriz completa. Rechaza listas que no contengan exactamente nueve números.

Implementación: `mean_var_std.py`.

## Ejecutar y probar

Python 3.12, con las versiones verificadas de `requirements.txt`:

```sh
python -m pip install -r requirements.txt
python main.py
python -m unittest test_module -v
```

Resultado: **3/3 pruebas originales aprobadas**. Los archivos de pruebas no fueron modificados.

Las imágenes generadas, cuando corresponde, están incluidas en este repositorio.

## Créditos

Datos, plantilla y pruebas: [freeCodeCamp](https://github.com/freeCodeCamp/boilerplate-mean-variance-standard-deviation-calculator). Implementación preparada con asistencia de Codex.
